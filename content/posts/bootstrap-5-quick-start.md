## 为什么选 Bootstrap 5

- 移动优先的响应式网格;
- 丰富的组件与工具类;
- 不依赖 jQuery, 体积更小。

### 实用技巧

1. 用 `d-flex` + `gap` 替代繁琐的 margin;
2. 使用 CSS 变量快速换肤;
3. 结合 `data-bs-*` 属性实现交互。

```html
<div class="card shadow-sm rounded-4">
  <div class="card-body">
    <h5 class="card-title">Modern Card</h5>
    <p class="card-text">Bootstrap 5 让样式变得简单。</p>
  </div>
</div>
```

希望这些小技巧对你有所帮助!
