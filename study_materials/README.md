# 24周流行病学通用学习包

适合生信转流行病与卫生统计的博士新生。每周4次必修＋1次选修；通用训练，不限定肠道疾病/微生物。
长期目标是中科院1区研究能力；本包不把24周训练等同于顶刊录用。

## 文件顺序

1. [总学习方案](01_总学习方案.md)：目标、分阶段路线、时间、项目、验收与后续原创研究。
2. [96次单次学习计划](02_96次单次学习计划.md)：稳定编号、论文依据、数据、任务与产出；另有24次选修。
3. [文献与数据资源库](03_文献与数据资源库.md)：38篇论文入口、数据获取等级与注意事项。
4. [单次学习与博客模板](04_单次学习与博客模板.md)：复制后填写，可按博客引擎改front matter。
5. [开课输入与协作规则](05_开课输入与协作规则.md)：最简指令与文献/数据/代码/博客协作流程。
6. [W01-S01预习示范](06_W01-S01_预习与博客示范.md)：第一课如何使用模板，明确尚未实际完成。

## 现在如何开始

```text
按24周通用流行病学学习方案，开始W01-S01。
本次3小时，R优先。
请帮我核验文献、安排阅读与实践，并按固定模板整理学习记录和博客Markdown。
明确区分原文结果、模拟、实际运行和待完成内容。
```

课程表所有课次当前均未开始。文件是计划/模板，没有提前生成或虚构分析结果。
论文书目与入口已检索，数据访问要求有说明；不是全部数据已下载、全部全文已读或全部代码已执行。
这是普通Markdown学习包，可保存到个人仓库或博客；没有安装为Codex技能，也没有自动发布博客。
