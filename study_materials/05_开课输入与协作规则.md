# 单次开课输入与长期协作规则

## 1. 最简开课指令

在同一聊天中，直接输入：

```text
按24周通用流行病学学习方案，开始 W01-S01。
本次可投入3小时，R优先。
请使用固定学习文档模板，帮我核验论文、准备学习步骤与实践任务，并整理可用于个人博客的Markdown。
请明确区分原文报告、实际执行结果、教学模拟和待完成内容。
```

以后只需换编号。例：
- W04-S03：匹配与嵌套病例对照。
- W06-S03：样条与连续变量处理。
- W09-S02：Cox与HR解释。
- W14-S03：IPTW与Overlap weighting。
- W19-S02：校准与Brier。
- W21-S03：Causal forest与独立评价。

如切换到新聊天，请附总方案、课程表中本次所在一周和模板；不要假设新聊天自动知道所有文件。只贴单次任务也可以，助手应据已给目标安排，不推测未见课程内容。

## 2. 完整输入格式（可选）

```text
【学习编号】WXX-SXX
【主题】从课程表复制
【本次目标】最多3项，或沿用总计划
【时间】3小时
【当前基础】R/Python与本主题掌握程度；可省略并采用入门默认
【上次成果/问题】文件或摘要；没有则写首次学习
【文献】沿用本次锚点；需要1篇近期应用或指定论文
【数据】优先公开小数据；允许模拟；已有数据则写来源与结构
【模式】完整支持：检索文献、数据核查、方法解释、必要代码和博客整理
【输出】固定模板Markdown；代码与表图作为配套；不要代发博客
【重点】例如设计/公式/实现/解释/验证
```

## 3. 助手每次应执行的流程

1. 识别编号、主题、先修和可用时间；默认3小时、R为主、疾病不限。
2. 核验1篇主锚点，按需补方法/近期应用。核对题名、年份、DOI/官方入口、全文/补充可得性、勘误/更正与撤稿状态。
3. 为每篇说明：为什么与本课相关，具体读哪些段落/图表。全文无法获取时如实标记，选择公开替代，不从摘要重建作者全部方法。
4. 找一套能获取、变量和时间适配的数据；记录来源、版本、单位、许可和获取状态。不默认公开论文意味着个体数据公开。
5. 确认本次属于设计练习、模拟、方法练习、原数据核心复现、独立验证或原创探索。能用简单公开数据时不要求新权限。
6. 给出本次时间表、3个学习目标、概念/假设、分析理由和实践步骤。先讲设计，后给模型。
7. 在用户已要求执行且环境/权限支持时，完成必要代码、运行与核验；不能运行则清楚交付待运行脚本和替代路径。不得写未发生的输出。
8. 实际运行检查：关键编码/时间/样本流、主要估计或性能、诊断/验证与表图一致性。使用与设计/估计器相容的方差或重采样。
9. 按04模板整理一份学习记录，并生成可发布的博客稿；如只有计划和文献阅读，则标题与draft状态要匹配，结果保持待完成。
10. 给3道自测题；参考答案与用户真实回答分开。结合用户反馈更新掌握状态。
11. 用实际结果/阅读状态更新学习日志，列出下一编号与需补知识。助手交付文档不等于学习者已掌握。
12. 默认只保存、展示或提供稿件；发布到博客是单独任务，不自动发布。

## 4. 输出约定

每次默认：
- `learning_note.md`：完整学习记录，保留运行/证据状态和私人复盘。
- `blog_post.md`：从学习记录整理为读者可理解的文章；有未完成工作则保持draft。
- `analysis.R`或`analysis.py`：需要计算时提供；设计课可省略。
- `figures/`、`tables/`：有实际计算才生成。
- `run_log.md`：实际运行、数据版本、未解决问题；不要含患者明细。
- `next_session.md`：下次可直接复制的输入。

文章长度默认800—1500字左右，复杂课可延长；每次不必都写长篇。可把同周四次合成一篇专题。
博客为标准Markdown，数学公式与Mermaid是否支持取决于你的博客引擎；必要时改成自生成PNG/SVG图或纯文本。
图片优先原创绘图；引用出版原图时核对许可。
若所在工具环境无法保存文件，交付可复制文本并说明，不能冒称已保存。

## 5. 只要部分帮助时

```text
按总方案 WXX-SXX，本次只帮我找文献：
1篇顶刊锚点＋1篇方法补充；核验书目、链接、阅读重点、数据代码和更正状态。
```

```text
按总方案 WXX-SXX，我已运行代码。请检查附件中的分析、表图和解释，
再按固定模板整理学习记录与博客稿。无法从附件核实的内容请标待核验。
```

```text
按总方案 WXX-SXX，数据无法下载。请找公开替代或设计模拟，
保持本次方法目标，明确这属于方法练习，不写成原论文复现。
```

```text
将WXX-S01至S04的学习记录合成一篇博客专题：
保留研究问题、方法理由、实际结果、限制和来源，删除重复内容，不补造缺失结果。
```
