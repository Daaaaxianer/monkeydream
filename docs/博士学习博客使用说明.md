# 博士学习博客使用说明（静态版）

## 每次学习到发布

1. 从博客进入“学习路线”，选择 W01-S01 等课程，阅读任务、最低产出与文献，复制开课指令。
2. 按学习包模板整理阅读卡、研究设计、R 代码、结果和局限。计划、原文报告、教学模拟与实际运行分开标注。
3. 复制 `content/post-template.md` 到 `content/posts/`，修改顶部 JSON 元数据；正文可从学习包模板复制。
4. 确认引用、数据入口与证据状态，设置 `draft: false`。运行构建并预览，或提交 GitHub 由 Actions 自动构建。

## 元数据

- title、slug、date：必填。slug 使用小写英文、数字和连字符；日期 YYYY-MM-DD。
- summary：文章摘要；updated：实际更新日期。
- article_type：note 方法笔记、reading 文献精读、replication 论文复现、project 研究项目、weekly 学习周记、other 其他文章。
- evidence_status：plan 计划、literature 文献解读、simulation 教学模拟、analysis 实际分析、partial 部分复现、replication 原数据核心复现、validation 独立验证、unspecified 未标注。
- category / category_slug：显示名和分类 URL 名。
- tags：对象数组，每项包含 name、slug。slug 使用小写英文、数字和连字符。
- sessions：课程编号数组，例如 ["W01-S01"]。
- code_url / data_url：公开代码和数据来源链接；无内容留空。
- draft：布尔值，true 不生成文章，false 公开。

顶部使用 JSON，字段名和字符串必须用双引号，不支持注释或末尾逗号。学习包中的通用 YAML 模板需要换成这里的 JSON 头部，正文无需更换。

## 写作显示

支持 Markdown 表格、脚注、引用、标题目录和 fenced code。代码块标注 r / python 等语言。行内公式 `$...$`、`\(...\)`；独立公式 `$$...$$`、`\[...\]`。公式浏览器渲染依赖 MathJax CDN；未加载时保留公式源码。建议预览后确认复杂公式。

图片放 `assets/uploads/`，文章正文使用 `![图题](../../../assets/uploads/figure.png)`。不要上传个人身份资料或受限原始数据。

课程关联用于学习路线检索公开文章，不代表任务已完成。网站不维护后台进度；完成日期、依据与反思写入公开学习总结或本地私人笔记。

## 私人记录与迁移

私人复盘保存在仓库之外。公开仓库源文件可被访问，draft 仅控制生成网站；构建会额外截去“## 私人记录附页”及后文。旧系统资料保存在本地 `_private_backup/django-original.zip`，不属于发布目录。

构建、测试、预览和 GitHub Pages 配置详见根目录 README。学习资源继承已有学习包，没有据此宣称已经阅读全部论文全文、下载数据或执行分析。
