# MonkeyDream 首页设计（2026-10-20）

使用 frontend-design 技能完成设计。原有小猴 Logo、森林绿主视觉、文章与公开地址保留。

## 当前方案

- 配色沿用森林绿 `#173D36`、叶绿 `#28634E`、浅灰绿 `#F5F7F2`、纸白 `#FFFFFF`、鼠尾草灰 `#64756B`、铜橙 `#BF7545`。
- 标题采用微软雅黑 UI / 苹方，正文使用本机中文无衬线字体，代码使用 Consolas；不请求外部字体。
- 所有内容左对齐。首页只保留欢迎主视觉、最新文章、工具项目三个主体部分。博客、归档、学习路线和资源通过现有导航进入。
- 两篇最新文章使用等宽两列，封面统一为 2:1；封面上下缘、文字区起点和阅读链接对齐，插图完整展示。手机切为单列。
- 删除“之前的记录”、作者侧栏和“循着兴趣继续探索”大区块，去掉重复介绍，缩短首页。
- 首页页脚保留第三方 Codex 重置内容，移除边框、白色卡片底和圆角，通过浅色转换与背景混合融入页脚；保留文字与来源链接。

```text
桌面                         手机
Logo                 导航    Logo / 菜单
欢迎语       研究手记插画     欢迎语 / 手记插画
最新文章封面 | 最新文章封面   最新文章（单列）
工具项目     | 工具项目       工具项目
品牌 / 导航 / Codex 状态      品牌 / 导航 / Codex 状态
```

## 参考与取舍

- [Astro Cactus](https://github.com/chrismwilliams/astro-theme-cactus) 及其[演示首页](https://astro-cactus.chriswilliams.dev/)：参考精简首页内容与明确的文章入口。本轮进一步删除重复区块，集中呈现最新文章与工具。
- [AstroPaper](https://github.com/satnaing/astro-paper)：阅读层级与搜索入口。
- [Blowfish](https://github.com/nunocoracao/blowfish)：全站视觉一致性。

仅参考设计组织，不复制主题代码与图片，不新增框架。研究手记、剪接与 RAG 封面为本站绘制的 SVG。调整后的首页不再为填满页面而增加卡片、标题或作者介绍。

## 验证

桌面实际测量两张封面的上下缘、宽度、正文起点和阅读链接位置一致；检查文章封面完整性与桌面、390px 手机的页脚融合。390px 和 320px 页面无横向溢出。四篇文章均保留于博客与归档。静态构建验证 32 个 HTML 页面及全部站内链接；现有四项测试通过。样式继续使用内容版本号。
