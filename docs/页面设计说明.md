# MonkeyDream 页面设计

本轮保留静态构建、原有文章与猴子 Logo，优化首页、博客索引、阅读页及移动布局。

## 设计方案

- 配色：纸白 `#FFFFFF` 为主体、深棕 `#3D271B` 为标题、橘棕 `#A5480B` 为可读链接、明橙 `#FF8E24` 为品牌点缀、杏色 `#FFF0DD` 为首页欢迎区域、灰棕 `#75695F` 为次要文字。
- 字体：中文标题优先使用本机思源宋体、宋体或宋体类字体，正文采用苹方、微软雅黑等本机无衬线字体；代码使用等宽字体。无需外部字体请求。
- 布局：正文左对齐，首页欢迎区域左侧文字、右侧原有小猴；文章以日期栏和正文栏组织，文章正文控制行宽，桌面目录独立放在右侧。
- 原则：视觉重点仅放在首页小猴与欢迎语。学习路线保留在博客里，首页只介绍作者并呈现最近五篇文章。所有装饰都服从阅读和导航。

```text
桌面首页                 阅读页              手机阅读页
Logo          导航       返回博客             Logo / 菜单
欢迎语        小猴       标题       目录       标题 / 文章信息
简短介绍                 文章信息   章节       展开目录
最近文章 / 全部文章      正文       导航       正文
日期   标题、摘要
页脚
```

## 对照需求后的调整

放弃整页米色、重复圆角卡片和大面积装饰渐变：它们无法表达这份个人博客的内容层次。杏色仅用于承接原有棕橙猴子形象，文章区保持白底。首页不增加课程、统计或仪表盘；复杂筛选移入可展开区域，手机目录默认收起。

## 检查重点

桌面与手机的首页、搜索筛选、移动菜单、文章目录与正文图片；键盘焦点、低动态偏好、代码复制，以及静态构建和链接完整性。

已检查桌面首页与 RAG 阅读页、390px 和 320px 页面；修正窄屏菜单换行和欢迎区标题挤压。验证关键词搜索、类型筛选、清除筛选、手机菜单及 Esc 关闭、目录展开与章节跳转、代码复制反馈。现有四项测试及 37 个静态页面的本地链接检查通过。样式与脚本地址附带内容版本号，更新后可加载对应资源。
