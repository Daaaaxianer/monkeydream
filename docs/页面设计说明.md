# MonkeyDream 全站视觉设计（2026-10-20）

本轮使用 frontend-design 技能，保留原有小猴 Logo、文章、静态构建和所有公开地址，重新设计首页与全站视觉。

## 参考与取舍

- [AstroPaper](https://github.com/satnaing/astro-paper)：参考明确的文字层级、阅读行宽与搜索入口。
- [Astro Cactus](https://github.com/chrismwilliams/astro-theme-cactus)：参考轻量内容导航、文章与项目并存的组织方式。
- [Blowfish](https://github.com/nunocoracao/blowfish)：参考首页、文章页和个人介绍之间的一致性。

仅参考设计组织，不复制主题代码与图片，不新增框架依赖。研究手记和两幅文章封面为本站绘制的 SVG。

## 设计方案

- 森林绿 `#173D36`：首页主视觉；叶绿 `#28634E`：链接与操作；浅灰绿 `#F5F7F2`：页面背景；纸白 `#FFFFFF`：文章与精选卡片；鼠尾草灰 `#64756B`：次要文字；铜橙 `#BF7545`：呼应原有 Logo 的少量插画点缀。
- 字体：标题使用微软雅黑 UI / 苹方的有力字重，正文采用本机中文无衬线字体，代码保留 Consolas。不请求外部字体。
- 排版：全部内容左对齐。首页由深绿研究手记主视觉、两篇新文、学习入口、较早文章和工具组成。阅读页是白色正文与独立的桌面目录；手机目录移入正文并默认折叠。
- 原则：视觉记忆点集中在研究手记插画。封面与实际文章主题对应，普通文章采用轻量列表；不添加无意义统计、重复卡片或装饰性渐变。

```text
桌面首页                        阅读页              手机首页
Logo                 导航       Logo / 导航         Logo / 菜单
欢迎语       研究手记插画        标题        目录     欢迎语
阅读入口                        正文        章节     研究手记插画
最新文章：剪接 / RAG             公式 / 配图          最新文章（单列）
学习路线 / 文献 / 工具           相邻文章             学习入口
之前的记录        作者简介                           之前的记录 / 工具
工具与项目                                          页脚
品牌          导航  Codex卡片
```

对照需求后，舍弃原先大面积暖杏色、宋体标题和仅有文字列表的首页。保留品牌小猴，以深绿及科研手记呼应生信、公共卫生和方法笔记。首页两篇新文配封面，其余内容用列表、入口与轻量工具栏组织，避免全站重复相同卡片。第三方 Codex 重置卡片保留在首页页脚，浅色适配并与导航、品牌分组。

## 验证

检查桌面与手机首页、RAG 与 SUPPA2 阅读页、关于、工具和学习入口；验证手机菜单、搜索及空结果、重置筛选、目录展开、公式与配图加载。完成 320px 窄屏与中间尺寸的溢出检查。静态构建校验 32 个 HTML 页面及全部站内链接，现有四项测试通过。CSS 继续使用内容版本号，避免旧缓存影响新版。
